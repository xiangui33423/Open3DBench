# 第五版官方容器验证

验证日期：2026-10-04（Asia/Shanghai）。第五版沿用第四版带接收端保护的多分支 MLS 与 HBT 重定位，为低层详细接入预留全局路由资源：M2 削减 70%，M3 削减 60%，其他路由层削减 50%，GRT 拥塞迭代保持 1 次。全部用例使用相同默认配置。

## 最终详细布线质量

对照为第四版 guarded 的真实完整评测；第五版为最终 `reserve_fast` 生产接口的独立重验，不用初筛候选指标替代。两例均完成固定官方 `-droute_end_iter 2`、最终 DRC、RCX、STA 和合法性检查，使用 16 线程。

| 用例 | 指标 | v4 | v5 | 绝对值变化 |
|---|---|---:|---:|---:|
| bp_fe | 最终 DRC | 4084 | 1811 | -55.66% |
| bp_fe | TNS / ns | -6562.16 | -6544.23 | -0.27% |
| bp_fe | WNS / ns | -3.26710 | -3.24734 | -0.60% |
| bp_fe | 线长 / μm | 1348627.87 | 1359350.51 | +0.80% |
| bp_multi | 最终 DRC | 13395 | 4800 | -64.17% |
| bp_multi | TNS / ns | -82031.10 | -83567.50 | +1.87% |
| bp_multi | WNS / ns | -16.89560 | -16.99270 | +0.57% |
| bp_multi | 线长 / μm | 3876927.61 | 3892767.95 | +0.41% |

bp_fe 的 DRC 减少 **55.66%**，TNS/WNS 均略有改善，线长增加约 0.80%。bp_multi 的 DRC 减少 **64.17%**；其 TNS 负值幅度增加 1.87%，WNS 恶化 0.0971 ns（约 0.57%），线长增加约 0.41%。因此本版取得明显 DRC 收益，同时保留对 multi 时序代价的明确记录。

TNS/WNS 的变化按负 slack 绝对值计算，绝对值减少表示改善。DRC、线长的增加表示代价。HBT 总数分别保持 1,533、3,456，超额 HBT 均为 0。

赛题权重为 TNS 25%、WNS 20%、Runtime 25%、线长 10%、DRC 10%、超额 HBT 10%。本轮以减少 DRC 为主要方向，同时核对其他评分项；未取得官方服务器综合评分，不将这里的相对变化直接当作正式总分。
