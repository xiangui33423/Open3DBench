# v25 验证与质量继承规则

校验优化已在两个 Python 版本各通过 35 项原有 guide/metadata 测试、415 组几何精确差分、288 对解析及异常差分，以及 GC 初始开/关与正常/异常状态恢复检查。八例共 97094 个网络的完整诊断字段、排序和打印报告与 v23 一致。

官方 Python 3.12 完整 BP checker CLI 五对测量中，原版中位 11.804 秒、候选 10.468 秒；五对输出、退出码和输入哈希均一致。这个测量不能代替总入口计时。

发布验收要求：使用冻结源码重新生成八例 GRT 并通过固定原生合法性检查；原始 ODB/GUIDE、完整 MLS 计划、实际物理编辑/选层脚本、原生元数据和两 die guide 与基准逐字节一致；五例完整质量经独立的严格继承证明核对原始和 canonical 物理输入、源评测完整终态、DRT2/RCX/STA/SPEF/HBT RC、固定输入/SDC/库/引擎和线程配置。任何一项不同就不能继承该例。原始与 canonical guide 分别比较，不能相互代用。
