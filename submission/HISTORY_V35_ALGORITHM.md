# v35 算法与输入一致性

保留 v34 的原始 HBT 位置优化、两 HBT 的普通 MLS 选网、分 die 全局布线和受约束增量微调。
关闭默认和回退配置中的多分支 MLS。配置解析拒绝重新启用该不符合当前比赛限制的拓扑；
规划校验独立要求每条 MLS 网络恰好两个 HBT、三个子网，防止旧计划或其他路径生成超限网络。
原始 3D 网络继续保留一个 HBT，不合并或拆分其原始逻辑连接。

从官方设计与平台 Make 配置求值 TECH_LEF、SC_LEF、ADDITIONAL_LEFS、LIB_FILES。
完整加载这些文件，包含当前 DEF 未实例化的宏；不再按实际使用单元裁剪 ODB 的库集合。
缺少官方配置时明确报错，不悄悄退回到会遗漏库的选择方式。

不修改输入 DEF、SDC、官方 LEF/Liberty、评估器、DRC 规则或寄生模型。规则应用于所有输入，无用例名分支。
