# v34：带几何约束的 HBT 微调与增量布线（实验包）

在 v25 默认容量下保留原有 MLS 选择和两轮 HBT 规划，随后最多八轮微调原有 HBT。
每条相邻网络的 HPWL、每条可确定方向的跨 die 驱动到接收端曼哈顿路径均不增长；
增量布线只处理受移动影响的网络。保留每次布线的完整 guide/拥塞报告写盘。
该规则用于所有输入，不按用例名切换。

FE/BE 的固定完整 DRT2/RCX/STA 相对 v25 均改善 WNS 和 TNS；DRC 增幅较小，
但串行入口耗时增加。本包保留作实验候选，不替换默认 v25，也不宣称达到 30 分。

| 用例 | v25 WNS/ns | v34 WNS/ns | v25 TNS/ns | v34 TNS/ns | v25 DRC | v34 DRC | 入口耗时变化 |
|---|---:|---:|---:|---:|---:|---:|---:|
| bp_fe | -3.17388 | -3.16301 | -6168.53 | -6140.66 | 1093 | 1115 | +7.17% |
| bp_be | -3.53885 | -3.52082 | -6209.19 | -6197.69 | 4061 | 4053 | +5.50% |

耗时为八线程本地原生完整入口，每版本每例预热一次，三组平衡顺序串行测量的中位数；
不是服务器时间。WNS/TNS 越接近零越好。完整质量只覆盖 FE、BE；另外六例仅有合法性。
bp_quad 遇到 GRT-0228，按原有策略从原始 CTS 重启回退配置后通过；此例不代表启用了全部微调。
详见 VALIDATION.md 和 ALGORITHM.md。

```bash
bash build.sh 32
bash run.sh <input_dir> <output_dir> <platform_dir> 32
```
