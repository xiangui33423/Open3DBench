# v34 算法与边界

原有 v25 功能见 HISTORY_V25_ALGORITHM.md。本版本的四个执行代码改动为 HBT 优化器、
MLS 规划器、默认配置和单进程分 die 布线 Tcl；原生 C++ overlay、入口、容量、路由层设置均保持 v25。

1. 完成原有两轮 HBT 规划与 MLS 选择，保留新 MLS HBT 的占位和网络选择。
2. 对原有 HBT 做最多八轮坐标下降，无接受移动时提前结束。每个相邻网络的 HPWL 不得增加；
   每个可确定的普通驱动到普通接收端跨 die 曼哈顿路径不得增加。
   模糊方向、多 HBT 网络族、特殊/保护网络不参与；新 MLS HBT 固定。
3. 每 die 先在本次输入的原有规划坐标生成基础全局布线，再启用原生增量回调并施加额外移动。
   HBT 暂时设为 PLACED，完成移动后恢复原放置状态；回调期间临时屏蔽另一 die 的关联网络，
   finally 恢复其标志。未使用历史缓存布线或固定用例名。
4. 每次 GRT 均保留完整的内存/ODB guide 和文本 guide/拥塞报告输出；
   最后一次增量 GRT 发布完整输出。无额外移动时沿用普通路径。
5. 保留 v25 的 GRT-0228 重试逻辑，从原始 CTS 在新进程使用已有回退配置。

几何约束不是时序保证。即使不相关的 global guide 不变，后续详细布线仍可能变化；
只有固定最终 DRT/RCX/STA 的结果用来判断 WNS、TNS 和 DRC。
未修改评分器、SDC、Liberty、RCX、HBT 电阻电容或工艺设计规则。
原生 estimated-SPEF 写出诊断与拟议修补不包含在本包中。
