# 历史记录：第二版离线原生验证

本文保留 2026-10-03 使用 `20260724` 离线镜像的历史实验记录。当前第三版官方 `20260914` 验证见 `VALIDATION.md`，第二版 `20260914` 原始官方对照见仓库 `OFFICIAL_VALIDATION.md`。不同评估器版本的时序指标应分别比较。

验证日期：2026-10-03。本版默认使用 HBT 重定位、动态需求、联合 HBT 落点、192 条共享网上限和 1 次 GRT 拥塞迭代。正式详细布线仍采用固定评估器的 `-droute_end_iter 2`。

## bp_fe 固定详细布线与时序

本地使用用户离线镜像中未修改的固定引擎、官方检查器、DRT/DRC/STA 脚本和指标收集器，DRT 均为 8 线程、2 次迭代。以下数值来自实际完整评测，不是几何预测。原生环境通过 `EVALUATOR_HBT_PARASITICS_TCL` 指定同一官方脚本路径；固定文件按镜像 checksum 验证。

| 指标 | 原始网表布线基线 | 已提交初版 v1 | 第二版 v2 | v2 相对 v1 |
|---|---:|---:|---:|---|
| DRC | 4,257 | 4,152 | 4,059 | 减少 93，约 2.24% |
| DRT 线长 (μm) | 1,378,685.12 | 1,383,673.91 | 1,342,836.13 | 减少 40,837.78，约 2.95% |
| TNS (ns) | -2,697.39 | -2,694.45 | -2,700.94 | 负时序损失增加约 0.241% |
| WNS (ns) | -1.35101 | -1.35174 | -1.36567 | 负时序损失增加约 1.031% |
| HBT 总数 | 1,149 | 1,213 | 1,533 | 增加 320，仍无超额 |
| 超出免费额度的 HBT | 0 | 0 | 0 | 不变 |

第二版同时降低入口耗时、详细布线线长和 DRC，时序有小幅回退。不能据此宣称所有指标都改善，也未计算或宣称官方总分。

完整评测先在保留隔离路由进程的参考入口执行。最终单进程入口重新导出 canonical DEF/guide 并调用官方检查器；其 raw DEF、guide、MLS plan 和 canonical DEF/guide 与参考逐字节一致，之后显式复用相同设计的完整 DRT/STA 结果。最终入口的 ODB 内部 guide IDs 因对象表复用有所不同，没有声称 ODB 二进制逐字节相同。已检查 guide 数量、标记、实际布局、连接、TRACKS、网类型和层容量调整字段；输出中恢复路由前的 metadata。

## 入口运行时间

首版通过 Git commit `1b19983d` 导出到独立临时目录重新运行；同一输入、同一原生引擎、同为 8 线程。时间是单次本地运行结果，不是评测服务器成绩。`runtime_seconds` 包含输入载入、准备、GRT、guide 检查、ODB 发布及重开验证，不包含源码编译、详细布线或入口最开始的 collateral/executable 解析。

| 用例 | 首版 v1 重测 (s) | 二版单进程 (s) | 减少 |
|---|---:|---:|---:|
| bp_fe | 40.018 | 27.161 | 32.13% |
| bp_be | 104.958 | 42.296 | 59.70% |

最终默认四参数入口另一次运行耗时 27.046 s，其 ODB、DEF、guide 和 MLS plan 与上述 27.161 s 对照入口均逐字节一致，确认未指定额外参数时也使用选定的配置。

bp_fe 相同初版入口关闭 MLS 的基线重测为 34.470 s。单进程模式复用 Liberty/设计，保留两次严格 die 层约束路由；省去多次重复载入、最终寄生估计与 ref-SDC 工作。最终仍由 OpenROAD 重开 ODB 验证。

## 八个公开用例的实际准备验证

全部 8 例都执行真实 OpenROAD LEF/DEF 载入、HBT 状态转换及编辑、DEF 导出，再调用官方不可变元件/引脚、逻辑等价、MLS 命名与家族连通、HBT 网格/边界/间距检查。全部 errors/warnings 为空，非 HBT 元件及封装引脚完全保留，HBT 超额为 0。此表仅表示准备阶段通过，不代表全部用例完成 GRT/DRT/STA。

最大 bp_quad 含 1,363,004 网。优化器仅复制 55,670 个包含旧 HBT 的网，其他网只读复用；副本阶段单次耗时从 54.387 s 降至 2.006 s，完整优化器耗时 6.106 s。4,096 个重定位及统计与优化前的结果完全一致。该微基准不能当作整个入口的加速比例。

bp_fe 和 bp_be 的最终单进程 GRT 输出均通过官方 canonical 合法性检查、guide 层归属与连通性检查，零错误/警告；bp_be 尚未完成新版的固定详细布线与时序评测。
